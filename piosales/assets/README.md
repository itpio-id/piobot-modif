# Brand assets

Drop the real files here with these exact base names (extension bebas: `.png`,
`.jpg`, `.jpeg`, atau `.webp` — app coba semua otomatis, fallback ke placeholder
kalau belum ada, tanpa perlu ubah kode):

- `logo.*` — logo ITPIO, transparan, disarankan persegi (mis. 256x256).
- `signature.*` — tanda tangan Fionni.
- `qris.*` — gambar QRIS ITPIO (boleh full poster atau sudah di-crop ke bagian QR + NMID saja).

Status saat ini: `logo.png`, `signature.png`, dan `qris.png` ✅ semua sudah
terisi asset asli. `qris.png` sudah di-crop otomatis supaya hanya menampilkan
kode QR-nya saja (tanpa poster/branding di sekitarnya).
