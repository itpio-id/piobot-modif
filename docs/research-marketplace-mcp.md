# Marketplace product search MCPs

**Checked:** 2026-11-13. This is a documentation and repository review; no live API calls or credentialed searches were made. Vendor pages describe advertised support, which still needs a small live check before adoption.

## Short answer

There are remote, cloud-callable options for these marketplaces. **ProLevelMax is the closest single hosted MCP for all three**; its Shopee and Tokopedia product sources document title, price, and product link. Its TikTok Shop keyword search documents title and price, but the basic search schema does not clearly promise product links for Indonesia. Its richer link-returning TikTok source currently says non-US markets may have incomplete data. **Nexscope Product Discovery** is a better documented TikTok Shop option for Indonesia when a product URL is required. **Bright Data** advertises dedicated Shopee and Tokopedia MCPs and has TikTok Shop keyword scraping, but its exact marketplace-specific MCP tool schemas are not public on the product pages. **API.SH** has clear cloud APIs/MCP access for Tokopedia and TikTok Shop, but no Shopee API was found in its current catalog.

These vendor services are distinct from a SERP/search-engine MCP: they claim to return marketplace listings or structured marketplace data. PioBot now uses the Apify Shopee scraper for direct listing data when an Apify token is configured; Bright Data remains a SERP fallback that extracts prices from indexed snippets. See [`api/_lib/brightdata-mcp.js`](../api/_lib/brightdata-mcp.js).

## What I would test next

Run one Indonesian keyword through ProLevelMax Shopee, Tokopedia, and TikTok Shop; inspect returned `title`, numeric/currency price, URL, region, and whether each item opens. If TikTok Shop `ID` URLs are missing or the results are weak, compare Nexscope `nexscope_tiktok_product_discovery` with `region: ID`. For an enterprise/managed alternative, inspect Bright Data's current `search_scrapers` catalog and confirm the actual scraper IDs and JSON schema. This is a recommendation based on published documentation, not a verified quality or uptime ranking.

The official [TikTok Research API](https://developers.tiktok.com/products/research-api/) is not a general substitute: access is restricted to approved non-commercial researchers, and its Shop product research is limited to eligible research use and EU product data.

## App implications

PioBot's Shopee Bright Data path is already remote-capable when `BRIGHTDATA_API_TOKEN` is configured, but it performs SERP search and parses snippets. Its Tokopedia and TikTok routes explicitly reject non-local requests. Nexscope's provider MCP is hosted, so moving TikTok search to Vercel would require changing the app's local-only gate and likely upgrading from its V1 search to the documented V2 Product Discovery tool. The Tokopedia local MCP has no hosted service URL in its README; replace it with a remote provider such as ProLevelMax or API.SH for Vercel. No credentials were created or configured during this research.

## Weak points

- Provider documentation and sample responses do not establish real-world result coverage, freshness, uptime, or terms of use; a live Indonesian-query trial is still needed.
- Product URLs are the main uncertainty for TikTok Shop `ID`: ProLevelMax's basic search doesn't document them, and its richer URL source warns about non-US markets; Nexscope documents URL fields but still needs live verification.
- Prices, credits, free tiers, and tool schemas can change. Recheck the linked product pages and request quotes immediately before integration.
